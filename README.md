# 한림 올인원 안내 애플리케이션

한림대학교 재학생을 위한 교내 통합 안내 애플리케이션입니다.  
캡스톤디자인 수업에서 3인 팀으로 개발하였습니다.

---

## Features

### 1. 교내 최적 경로 안내
교내 지도를 기반으로 목적지까지 최적 경로를 탐색합니다.

### 2. 학식 영양정보 안내
학생식당 메뉴의 칼로리 및 영양성분 정보를 제공합니다.

### 3. 버스 실시간 노선 안내
춘천역 ↔ 한림대학교 간 버스 실시간 운행 정보를 제공합니다.
